## 🔄 STEP-BY-STEP FLOW

```
STEP 1: Server Startup
   ┌─────────────────────────────────────┐
   │ java oneToOneServer                 │
   │ → Binds to port 12350               │
   │ → Waits for connection              │
   └─────────────────────────────────────┘

STEP 2: Client Connection
   ┌─────────────────────────────────────┐
   │ java oneToOneClient                 │
   │ → Connects to localhost:12350       │
   │ → Connection established ✓          │
   └─────────────────────────────────────┘

STEP 3: Thread Creation (Both Sides)
   ┌─────────────────────────────────────┐
   │ Main Thread: Handles sending        │
   │ Listener Thread: Handles receiving  │
   └─────────────────────────────────────┘

STEP 4: Bidirectional Communication
   ┌─────────────────────────────────────┐
   │ Server → Client: "Server: message"  │
   │ Client → Server: "message"          │
   │ (displayed as "Client: message")    │
   └─────────────────────────────────────┘

STEP 5: Disconnection
   ┌─────────────────────────────────────┐
   │ Either side closes                  │
   │ → IOException caught                │
   │ → "Disconnected" message shown      │
   └─────────────────────────────────────┘
```

## 📝 KEY POINTS

✅ Port: 12350
✅ Protocol: TCP Socket
✅ Threading: 2 threads per process (Send + Receive)
✅ Message Format: Server prefixes "Server:", Client messages shown as "Client:"
✅ Bidirectional: Both can send/receive simultaneously
