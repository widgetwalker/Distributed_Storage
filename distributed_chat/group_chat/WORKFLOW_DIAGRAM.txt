┌────────────────────────────────────────────────────────────────────────────────┐
│                            THREAD ARCHITECTURE                                  │
└────────────────────────────────────────────────────────────────────────────────┘

SERVER PROCESS:
├── Main Thread (Accept Loop)
│   └── Continuously accepts new client connections
│
├── ClientHandler Thread-1
│   ├── Reads messages from Client-1
│   └── Broadcasts to other clients
│
├── ClientHandler Thread-2
│   ├── Reads messages from Client-2
│   └── Broadcasts to other clients
│
└── ClientHandler Thread-N
    ├── Reads messages from Client-N
    └── Broadcasts to other clients


CLIENT PROCESS:
├── Main Thread (Sending)
│   ├── Reads input from console
│   └── Sends to server
│
└── Listener Thread (Receiving)
    ├── Reads messages from server
    └── Displays on console

╔════════════════════════════════════════════════════════════════════════════════╗
║                              WORKFLOW SUMMARY                                  ║
╚════════════════════════════════════════════════════════════════════════════════╝

1. SERVER INITIALIZATION
   └─▶ Create socket, bind to port, initialize client list

2. CLIENT CONNECTION
   └─▶ Client connects → Server accepts → Create handler thread → Send username

3. JOIN NOTIFICATION
   └─▶ Server broadcasts join message to all existing clients

4. MESSAGE EXCHANGE
   └─▶ Client sends → Server receives → Format → Broadcast to all except sender

5. MONITORING
   └─▶ Server displays all messages on console for monitoring

6. DISCONNECTION
   └─▶ Client disconnects → Server detects → Broadcast leave message → Remove client

7. CONTINUATION
   └─▶ Remaining clients continue chatting normally
