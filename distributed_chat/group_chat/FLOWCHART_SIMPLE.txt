┌────────────────────────────────────────────────────────────────────────────┐
│ 1. MULTI-CLIENT SUPPORT                                                    │
│    • Server accepts unlimited client connections                           │
│    • Each client runs in separate thread                                   │
│    • Dynamic client list management                                        │
└────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────┐
│ 2. MESSAGE BROADCASTING                                                    │
│    • Messages sent to ALL clients except sender                            │
│    • Server monitors all messages                                          │
│    • Thread-safe broadcast mechanism                                       │
└────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────┐
│ 3. JOIN/LEAVE NOTIFICATIONS                                                │
│    • Broadcast when client joins                                           │
│    • Broadcast when client leaves                                          │
│    • Server displays connection status                                     │
└────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────┐
│ 4. CROSS-NETWORK SUPPORT                                                   │
│    • Client prompts for server IP address                                  │
│    • Supports localhost for local testing                                  │
│    • Supports network IP for remote connections                            │
└────────────────────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────────────────┐
│ 5. USERNAME IDENTIFICATION                                                 │
│    • Each client provides username                                         │
│    • Messages tagged with username                                         │
│    • Default username if not provided                                      │
└────────────────────────────────────────────────────────────────────────────┘
