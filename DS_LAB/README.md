# Distributed Systems Lab (DS_LAB) - User-Input Based Simulations
This folder contains 10 fundamental distributed systems experiments implemented as separate Server/Master and Client/Worker programs.

## Experiments Included
1. **3. Message Passing**: Basic IPC across two processes.
2. **4. Lamport Clock**: Logical timestamp synchronization.
3. **8. Berkeley Sync**: Physical clock synchronization in a network.
4. **10. Lamport Mutex**: Distributed mutual exclusion with clocks.
5. **11. Ricart-Agrawala**: Optimized mutual exclusion logic.
6. **13. Chat App**: Socket-based multi-user chat.
7. **16. Deadlock Detection**: Wait-for-graph cycle detection.
8. **19. Distributed Sorting**: Parallel Merge/Quick sort logic.
9. **20. MapReduce**: Word count simulation via Map-Reduce paradigm.
10. **21. Prime Calculation**: Distributed numerical ranges for prime search.

Each subfolder contains separate files to be run on different systems or network terminals. Use IP addresses to connect nodes across characters.
